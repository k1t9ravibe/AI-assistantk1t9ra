# AI Assistant

Личный ИИ-ассистент для Windows на базе Claude (Anthropic API) и Electron.

## Возможности

- Чат с историей: несколько диалогов, переименование и удаление; всё хранится локально в `%APPDATA%\AI Assistant\chats.json`.
- Файлы: перетащи в окно, прикрепи скрепкой 📎 или вставь скриншот через Ctrl+V. Поддерживаются картинки (PNG/JPG/GIF/WebP), PDF и любые текстовые файлы (код, txt, md, csv, json…).
- Горячая клавиша **Ctrl+Shift+Space** показывает и прячет окно из любой программы (меняется в настройках).
- Голосовой ввод 🎤 (или **Ctrl+M**): речь распознаётся моделью Whisper прямо на ПК, без отправки звука в интернет. Модель (~200 МБ) скачивается один раз при первом использовании. Язык и модель (Base — быстрее, Small — точнее) выбираются в настройках.
- Автозапуск вместе с Windows (включается в настройках): приложение стартует свёрнутым в трей.
- Работа в трее: крестик прячет окно, выход — через правый клик по иконке в трее.
- Ответы в Markdown с подсветкой блоков кода и кнопками «Копировать», кнопка «Стоп» для остановки ответа.
- Настройки: модель (Opus 5.5 / Sonnet 5.5 / Haiku 5.5), глубина размышлений, системная инструкция.

## Запуск

1. Получи API-ключ на [console.anthropic.com](https://console.anthropic.com) → API Keys.
2. Нужен Node.js 20+. Установи зависимости:
   ```
   npm install
   ```
3. Запусти: двойной клик по `start.bat` или командой `npm start`.
4. При первом запуске откроются настройки: вставь ключ. Он хранится зашифрованным средствами Windows (`safeStorage`).

## Сборка установщика (.exe)

```
npm run dist
```

Установщик появится в папке `dist/`.

## Структура

- `src/main.js` — основной процесс: окно, трей, горячая клавиша, хранилище, запросы к Claude со стримингом.
- `src/preload.js` — безопасный мост между интерфейсом и основным процессом.
- `src/renderer/` — интерфейс (HTML/CSS/JS).
