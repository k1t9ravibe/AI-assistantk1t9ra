# Ассистент закупщика

Личный веб-сайт с ИИ-ассистентом закупщика квазигосударственного сектора Республики Казахстан на базе Claude (Anthropic API). Ассистент работает как юрист-закупщик: отвечает на вопросы по процедурам, срокам и способам закупок, пишет техспецификации и проверяет их на «заточенность», проверяет документацию, заявки и договоры, готовит письма и ответы на жалобы, сравнивает КП. Опирается на нормативные документы из базы знаний.

## База знаний

- В разделе **📚 База знаний** добавь законы, правила закупок, типовые формы и внутренние положения. Поддерживаются PDF с текстовым слоем, DOCX, TXT и HTML (например, сохранённые страницы adilet.zan.kz). Текст извлекается один раз и хранится на сервере в `data/knowledge/`.
- Все документы базы целиком передаются модели (контекст 1M токенов) с включённым цитированием. В ответе после фрагмента стоит сноска [n], а внизу — список «Источники» с точным текстом нормы.
- База кэшируется на час: повторные вопросы в течение часа обходятся по входным токенам примерно в 20 раз дешевле первого.
- Состав базы и инструкция фиксируются при первом сообщении чата, изменения применяются к новым чатам.
- Инструкция юриста-закупщика лежит в `server/prompts/procurement.md`. Дополнительные указания можно дописать в настройках сайта.

## Возможности

- Чаты с историей: несколько диалогов, переименование и удаление. Хранятся на сервере в `data/chats.json`.
- Файлы к сообщению: перетащи в окно, прикрепи скрепкой 📎 или вставь скриншот через Ctrl+V. Поддерживаются картинки, PDF, DOCX и текстовые файлы.
- Голосовой ввод 🎤 (или **Ctrl+M**): речь распознаётся моделью Whisper прямо в браузере, звук на сервер не уходит. Работает только по HTTPS или на localhost.
- Ответы в Markdown с кнопками «Копировать» и кнопкой «Стоп». Если закрыть вкладку посреди ответа, он всё равно допишется и сохранится в чате.
- Настройки: модель (Opus 5.5 / Sonnet 5.5 / Haiku 5.5), глубина размышлений, дополнительные указания.
- **Alt+N** — новый чат.

## Запуск

1. Нужен Node.js 20.12 или новее.
2. Установи зависимости:
   ```
   npm install
   ```
3. Скопируй `.env.example` в `.env` и заполни: `ANTHROPIC_API_KEY` (ключ с [console.anthropic.com](https://console.anthropic.com) → API Keys) и `APP_PASSWORD` (пароль для входа на сайт).
4. Запусти:
   ```
   npm start
   ```
   Сайт откроется на http://127.0.0.1:3000.

Для разработки: `npm run dev` перезапускает сервер при изменении файлов.

## Размещение в интернете

API-ключ хранится только на сервере, браузер его не видит. Сайт защищён паролем из `APP_PASSWORD`; без пароля сервер предупредит об этом при старте.

Рекомендуемая схема: Node слушает `127.0.0.1:3000`, а снаружи стоит nginx с HTTPS (например, сертификат Let's Encrypt). HTTPS нужен для микрофона и чтобы пароль не передавался открытым текстом. Пример блока nginx:

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_buffering off;          # ответы приходят потоком
    proxy_read_timeout 600s;      # длинные ответы на сложные вопросы
    client_max_body_size 100m;    # загрузка документов в базу
}
```

Чтобы сервер работал постоянно и поднимался после перезагрузки, запусти его через pm2 (`pm2 start server/index.js --name zakup`) или systemd. Папку `data/` включи в резервное копирование: там чаты, база знаний и настройки.

## Структура

- `server/index.js` — сервер: вход по паролю, чаты, настройки, загрузка файлов, запросы к Claude с потоковой передачей ответа.
- `server/knowledge.js` — база знаний: извлечение текста из PDF/DOCX/HTML, хранение, сборка документов для запроса.
- `server/prompts/procurement.md` — инструкция ассистента-закупщика (его «мозги»).
- `public/` — интерфейс: `index.html`, `renderer.js`, `api.js` (обмен с сервером), `voice.js` (голосовой ввод), `login.html`.
